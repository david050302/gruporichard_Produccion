## Antes de publicar
1. Si compras otro dominio, desde la raíz ejecuta: `python set_domain.py https://tudominio.pe`
2. Sube todo el contenido de esta carpeta al repositorio/hosting.
3. En Google Search Console agrega la propiedad del dominio final y envía `/sitemap.xml`.
4. En el Perfil de Empresa de Google agrega la URL final.
5. Crea Google Ads recién con el dominio final y añade su etiqueta de conversión/Analytics; el código viejo de Desmonte Lima NO fue copiado para no mezclar mediciones.
